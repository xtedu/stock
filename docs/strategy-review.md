# 策略体检报告：这套系统和机构差在哪，胜率该从哪提

> 结论先行版。所有判断都对应到具体代码位置，可逐条复核。
> 审视范围：`backend/app/services/` 全部策略模块 + `docs/algorithm.md` + `Picks.vue` 披露的回测口径。

---

## 0. 一句话结论

**这套系统的工程完成度远高于它的策略完成度。**

- 工程侧：幂等、断点续传、盘中/收盘双链路、三层去重、fail-safe 的 AI 回填 —— 这是专业水准，比大多数个人项目高一档。
- 策略侧：本质是 **3 套收益来源互相冲突的信号 + 1 个提醒器**，没有组合层、没有成本模型、没有评估闭环。`Picks.vue` 自己披露的 **周频 20 日超额 +0.34pp、t=0.35**，翻译过来就是：**这套选股在当前样本上没有可被证明的 alpha**。

所以"怎么提高胜率"这个问题，答案不是调参数、加因子，而是：**先让结论可以被证伪，再把仓位纪律补上，最后才谈因子。**

## 1. 诊断：它其实是四套策略，而且方向相反

| 模块 | 代码 | 收益来源（押什么） | 隐含持有期 | 因子方向 |
|---|---|---|---|---|
| 优质股池 | `screener.py` | ROE 35% + 增速 + 现金质量 + PE 分位 | 1 年以上 | 质量/价值（均值回归） |
| 安全区间 | `safety_zone.py` | MA250 乖离率，跌破下沿就提醒 | 1-3 个月 | 均值回归（越跌越买） |
| 每日三只 | `pick.py` | 利润增速 70% + 营收增速 30% 的池内分位，且要求 MA20 向上 | 20 日左右 | 动量（越强越买） |
| 妖股梯队 | `yaogu.py` | 涨停接力 + 题材纯度 + 首板位置 | 1-3 日 | 情绪动量（极端动量） |

**问题不在"四套"，在于它们共用同一个账户、同一笔钱、同一套 UI，却没有一层统一的资金分配规则。**

具体冲突点：`monitor.py:68` 的触发条件是 `price < zone_low`（跌得越狠越该买），而 `pick.py:204-207` 的排序是增速分位越高越好、且 `L194` 要求 MA20 向上（越强越该买）。一个人在同一天收到两个提醒，一个是"某某跌破低估区，右侧确认了快买"，另一个是"某某增速全池第一，快买"—— **这两个"快买"在因子空间里几乎正交，混在一起执行，等于把两套策略的 alpha 互相稀释成 beta。**

## 2. 与大资本的系统性差异

### 2.1 硬差距（不是"人家资源多"，而是"人家有而你没有的环节"）

| 环节 | 本项目现状 | 机构标配 | 性质 |
|---|---|---|---|
| 因子库 | 5 个手工因子（`screener.WEIGHTS`） | 50-200 个因子 + Barra/Axioma 风险模型正交化 | 量级差 |
| 权重确定 | 经验赋值 + 单次分段回测 | IC / IR 检验 → walk-forward → 样本外确认 | **方法论差** |
| 中性化 | 无 | 行业 + 市值 + 风格三重中性 | **致命** |
| 组合构建 | Top3，行业≤2（`pick.py:216`） | 优化器 + 跟踪误差约束 + 风险预算 | 中等 |
| 成本模型 | 无 | 佣金+印花税+冲击成本+VWAP 滑点 | **致命** |
| 回测 | 周频 88 期，一段行情 | 10 年+，跨牛熊，含流动性/涨跌停/停牌约束 | **致命** |
| 风控 | 无止损、无仓位管理、无空仓规则 | VaR、回撤预算、事前事后归因 | **致命** |
| 数据 | AKShare/东财免费源，现价股列表 | Wind/聚源 Point-in-Time + 另类数据 | 大 |
| 评估 | 选股结果不落库（`pick.py` 只有内存 `_CACHE`） | 每日组合净值 + Brinson 归因 | **致命** |

### 2.2 但你在结构上有四个机构拿不到的优势

这一节比上一节更重要 —— **不要在机构的主战场（大盘蓝筹的深度研究、日频量价高频）上正面竞争，那是必输的**。

| 你的优势 | 为什么机构做不到 | 应该怎么用 |
|---|---|---|
| 容量无约束 | 公募单票不能超 10%、不能持有超 5% 流通股；微盘股根本买不进去 | 专做 30-100 亿市值、日均成交 1-3 亿的票（`pick.py` 已经卡了 1 亿成交额，方向对） |
| 可以空仓 | 股票型基金仓位下限 80%，混合型 60% | 把 `compute_context` 的 regime 变成真正的仓位开关（见 4.2） |
| 可以等 | 机构按季度排名、按月度考核，扛不住半年不涨 | 允许"低估区挂单等 3 个月"，这是均线回归策略的天然主场 |
| 可以集中 | 机构被迫分散到 50-100 只 | 3-5 只集中持仓，但**必须配止损**，否则集中就是放大亏损 |

### 2.3 一个必须纠正的认知

机构超额收益的来源其实只有四类：

1. **风险溢价**（价值/动量/质量/小盘因子）—— 拥挤、公开、衰减最快。你的系统目前只押这一类。
2. **信息优势**（分析师预期修正、产业链调研、专家网络）—— 项目完全没有，但**这是散户唯一能靠"行业理解"补上的一类**。
3. **交易优势**（T+0 底仓、算法拆单、做市流动性提供）—— 你没有。
4. **结构性优势**（打新、定增折价、大宗接盘、指数纳入被动买盘）—— 散户可参与打新/可转债，但项目未涉及。

**结论：想提胜率，得从第 1 类往第 2 类迁移 —— 用"你比机构更早理解某个行业"替代"你和机构比谁算 PE 分位算得快"。**

## 3. 先定义"胜率"，否则优化方向一定错

`胜率` 单独拿出来是个陷阱指标。真正的目标函数是期望值：

```
期望收益 = p × 平均盈利 − (1 − p) × 平均亏损
```

- 胜率 40%、盈亏比 3:1 → 期望 +0.20R
- 胜率 60%、盈亏比 1:1 → 期望 +0.20R

两者等价。**而提高盈亏比（加止损、让利润奔跑）比提高胜率容易一个数量级**，因为它不依赖预测精度，只依赖纪律。

另外"胜率"必须先锚定三件事，否则无意义：

| 维度 | 必须明确 | 你的情况 |
|---|---|---|
| 持有期 | 1 日 / 20 日 / 60 日？同一信号在不同持有期胜率能差 20pp | 你的实际习惯是 **1-3 个月**，但系统产出的是 **日频信号** —— 这是错配 |
| 比较基准 | 绝对收益 or 相对中证 500 / 中证 1000？ | 全系统**没有任何基准指数数据**（`models.py` 无指数表） |
| 含费与否 | 含双边成本后是否仍为正 | 完全没有成本模型 |

**建议口径**：`20 日、相对中证 1000 的超额 > 0` 记为一胜，含双边 0.13% 成本。

## 4. 现有回测结论的可信度审计

`Picks.vue:94` 写着："周频 20 日超额 +0.34pp（t=0.35），2026 年已接近市场平均"。

按这组数可以反推：20 日超额收益的标准差 ≈ `0.34 × √88 / 0.35 ≈ 9.1pp`。由此有四个结论，都很硬：

| 问题 | 计算 | 含义 |
|---|---|---|
| **样本量远远不够** | 要让 0.34pp 的超额达到 t=2，需要 `(2×9.1/0.34)² ≈ 2863` 期 ≈ **55 年** | 不是"再调调"，是"这个效应量本身就不值得交易" |
| **重叠样本虚高 t 值** | 周频观测 20 日前瞻收益 → 4 倍重叠，有效独立样本仅 ≈22，t 需除以 ≈2 | 真实 t ≈ **0.17**，比披露的更接近 0 |
| **一段行情定全部结论** | 88 期 ≈ 1.7 年，且跨越单边行情 | `compute_context` 的结论"行业趋势/资金流/涨停热度作为门槛均为负贡献"，**在这个样本上不成立为事实**，只能是"没测出来" |
| **成本可能吃掉全部超额** | 0.34pp/20日 → 年化毛超额 ≈ 4.25%；若周频全换手，双边约 0.13%×50 ≈ 6.5% | **毛超额很可能小于交易成本** |

**这就是为什么说"加因子"现在没有意义：你无法区分"新因子有效"和"噪声恰好在这 88 期表现好"。**

## 5. 提高胜率：三层动作，按投入产出排序

### L1 · 代码级修正（1-2 天，先做，因为这是"确定性错误"）

| # | 问题 | 位置 | 修法 | 预期影响 |
|---|---|---|---|---|
| 1 | **前视偏差**：用 `report_date` 排序取近 4 期财务，没过滤"是否已披露" | `screener.py:54-57`、`:96-104` | `pick.py:32-43` 已经写好了 `_avail_date()`，抽到公共模块，`screener` 复用 | 修掉"用未来财报选股"，历史胜率会**下降**到真实水平——这是好事 |
| 2 | **妖股打分用代理而非真值** | `yaogu.py:239-290`、`:615-628` | `_fetch_limit_reasons()` 已解析出 `float_mv_yi / turnover_rate / seal_amount_yi / break_count`，但打分仍在用"成交额代理市值、振幅代理换手"。直接换真值，并把 `seal_amount_yi / float_mv_yi`（封单占流通市值比）作为新因子 | 六维打分信息量立刻上一档，`L2 价格≤10元` 这类粗糙门槛也能换成分层加权 |
| 3 | **加成本模型** | `pick.py` 打分/回测链路 | 双边 0.13%（佣金 0.025%×2 + 卖出印花税 0.05% + 滑点 0.03%） | 让所有"超额"变成可信数字 |
| 4 | **选股结果落库** | `models.py` 新增 `picks` 表 | `date/code/score/close/fwd_ret_5_10_20_60`，每天写入 | **这是全部评估的基础，没有它后面所有改动都是盲改** |
| 5 | 幸存者偏差 | `datafeed.py:36` `ak.stock_info_a_code_name()` 只有现价股 | 至少记录退市股，或把回测样本限定在"当时已上市 3 年"的交集上 | 回测收益率会被高估，需在结论上打折 |

### L2 · 逻辑级升级（最有可能真正提高胜率的部分）

**6. 把 regime 从"展示"变成"仓位开关"（单项收益最大）**

`pick.py:302-413` 已经算出了 `offensive / neutral / defensive` 三态，但只在页面上写一句"环境提示"。改成硬规则：

```
defensive  → 只允许"低估 + MA20 向上"双条件，仓位 ≤ 30%
neutral    → 正常仓 ≤ 60%
offensive  → 可满仓
```

理由：A 股策略之间 80% 的收益差异来自"有没有躲过系统性下跌段"，而不是选股精度。这是提升胜率性价比最高的一招，因为它不依赖任何预测能力，只依赖纪律。

**7. 入场从"单一条件"改成"价值 × 动量"双确认**

现在 `monitor.py:68` 只判 `price < zone_low`，`left/right` 只是个标签（`:72-81`）。文档自己承认的"阴跌接刀"就是这个原因 —— 低估区覆盖 55% 的标的，说明下限根本没起到区分作用。

改成三条件同时成立才提醒：

```
① price < zone_low                        （便宜）
② ma20_slope_up == True                   （止跌转强）
③ ret20 > 中位数 或 相对中证1000 20日超额 > 0   （有相对强度）
```

学术与实证都很清楚：**价值因子与动量因子的交互项，IR 显著高于任一单因子**。这一步能把"接飞刀"的比例压下来，是胜率提升最直接的一处。

**8. 补一个"预期修正"因子**

A 股长期最稳的 alpha 之一，与增速因子正交（增速看已实现，预期修正看未实现）。免费可得：

- `ak.stock_profit_forecast_em()` 一致预期净利润变动
- `ak.stock_yjyg_em()` 业绩预告（预增/略增/扭亏）
- 研报评级上调家数（`stock_research_report_em`）

做法：给 `pick.py` 的分数加第三项，权重建议 `利润增速 50% + 营收增速 20% + 预期修正 30%`，且必须先在小样本上验证 IC 再上线。

**9. 行业 + 市值中性化**

`pick.py:216` 只做了"同行业最多 2 只"，不够。高增速股天然扎堆在少数行业（2026 年是 AI/电子），Top3 实际是一个行业 beta。做法：增速分位改成**行业内分位**，再跨行业按市值分组取分位。这一步不提升单票胜率，但**大幅降低组合回撤**——而回撤是复利的天敌。

**10. 换手控制**

你的实际持有期是 1-3 个月，而系统每天产 Top3。加一条"连续 2 期入选才买入"，或改成双周调仓，把信号噪声过滤掉一半。

**11. 止损/止盈规则化（改善盈亏比，不改善胜率）**

- 硬止损 `-12%`（或 `-2.5σ20`，项目已有 `warn_line` 的 σ 计算可直接复用）
- 时间止损：20 日不涨即出
- 移动止盈：从最高点回撤 15% 出

对亏损中的持仓尤其重要 —— 现在系统只有"买入提醒"，**整个项目没有一行卖出逻辑**（`models.py` 也没有持仓表）。

### L3 · 结构性优势（中长期，真正拉开差距的地方）

**12. 把 AI 的角色从"加分项"改成"否决项"**

当前 `llm.compare()` 让模型输出"看多/中性/看空"——这是模型最不擅长的任务。改成输出风险清单：

```json
{"code": "600xxx", "risk_flags": ["大股东质押 68%", "商誉占净资产 41%", "3 个月内解禁 12%"]}
```

LLM 在**读文本找风险**（公告、诉讼、减持、审计意见、财务与现金流背离）上比预测涨跌可靠一个数量级。而且这正好对应机构"负面清单否决"的风控逻辑 —— 胜率提升来自"少踩雷"，而不是"多猜对"。

**13. 只在自己有信息优势的行业做深度**

你是教育培训 + LLM/GEO 背景。这个认知差在 AI 应用、教育信息化、算力链、GEO 服务商这类"新概念商业化路径"上，比机构的研究员更早、更深。全市场筛"利润增速前 3"是没有护城河的；在自己懂的 2-3 个行业里做 20 只深度跟踪，才有。

**14. 底仓收益**

打新（沪深市值配售）、可转债双低轮动 —— 与选股策略低相关，是提升组合"整体胜率"最廉价的方式，且完全不占用研究精力。

## 6. 妖股模块单独说：它是另一场游戏

`yaogu.py` 的定位是"涨停接力"，这本质是**游资主导的博弈**，对手是量化私募和职业打板席位。这里：

- 胜率天然在 30-40%（靠盈亏比取胜），**不可能通过调参把胜率提到 60%**；
- 项目现在**完全没有卖出规则和回测** —— 只有选股展示，等于只有观点没有策略；
- 它的信息优势应当是"快"和"细"（封单强度、首封时间、炸板次数、席位），而这些字段 `_fetch_limit_reasons()` **已经抓到了却没进打分**（见 L1-2）。

**建议：把妖股模块和小资金彻底隔离**（单独账户、≤10% 总资金），并且必须先补一个 T+1 卖出规则的回测再实盘。否则它对本金曲线的贡献大概率是负的，还会污染你对其他策略的判断。

## 7. 建议的实施顺序（每步都要能验证）

| 阶段 | 做什么 | 验证标准 |
|---|---|---|
| P0（本周） | picks 落库 + 成本模型 + 基准指数（中证 500/1000）入库 | 能画出"策略 vs 基准"的日净值曲线 |
| P1 | 修前视偏差；妖股换真值；regime 变仓位开关 | 修正前的胜率/回撤对比表（预期：修正后收益下降但更真实） |
| P2 | 双确认入场（低估 + MA20 向上 + 相对强度） | 20 日胜率、平均亏损、最大回撤三指标同时改善才算有效 |
| P3 | 预期修正因子 + 行业内中性化 | 滚动 12 期 IC > 0.03 且 IR > 0.3 |
| P4 | AI 改否决项 + 止损规则化 | 平均亏损幅度下降、盈亏比 > 2 |

**任何一步如果三个指标没有同时改善，就回滚。** 这是对抗过拟合的唯一办法。

## 8. 一页速查

| 问题 | 一句话 |
|---|---|
| 和大资本最大差别 | 他们有风险模型 + 成本模型 + 评估闭环，你只有因子和界面 |
| 你的真实优势 | 容量、空仓自由、等待自由、集中自由 —— 全在"纪律"层面，不在"聪明"层面 |
| t=0.35 怎么读 | 要么效应量太小不值得做，要么样本太短测不出。两种情况下都不该加因子 |
| 提胜率第一杠杆 | regime 仓位开关（躲过系统性下跌） |
| 提胜率第二杠杆 | 价值 + 动量双确认（不接飞刀） |
| 提胜率第三杠杆 | AI 从加分项改为否决项（少踩雷 > 多猜对） |
| 最该补的不是因子 | 是 `picks` 落库 + 成本 + 基准 —— 没有它们，所有优化都是盲改 |
| 妖股模块 | 另一场游戏，隔离资金，先补卖出回测 |
